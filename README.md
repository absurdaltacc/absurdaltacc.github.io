# Absent

Absent is a private web playground with a simplified black-and-silver shell, browser tools, games, media, cloud syncing, and extension support.

## features
- nice ui
- thousands of games aggregated from multiple sources
- free anime streaming
- cloud syncing
- functional chrome extensions support
- very efficient
- private by design

## self-hosting
```bash
# install and run
bun install
bash setup.sh
```
## local development
```bash
bun i
bun dev
```
